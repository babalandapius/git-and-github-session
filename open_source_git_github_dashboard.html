Module 01

Environment Setup & Configuration

1

Install Git CLI

Windows
winget install --id Git.Git -e --source winget
macOS
brew install git
Linux (Debian/Ubuntu)
sudo apt update && sudo apt install git -y
2

GitHub Account & Auth

  • Create Account: Sign up at github.com with a professional username.
  • SSH Key / PAT: Set up an SSH Key or Personal Access Token in Settings > Developer Settings for seamless authentication.
3

Configure Git Identity

Tell Git who you are before committing code locally:

# Set global user name
git config --global user.name "Your Name"
# Set global user email
git config --global user.email "your@email.com"

Module 03

Local CLI Command Cheat Sheet

git init

Initialize Repository

Creates a new blank `.git` tracking directory in the current folder.

git status

Check Working Tree State

Displays untracked, modified, or staged files awaiting commit.

git add .

Stage All Files

Adds all current folder changes to the Staging area buffer.

git commit -m "..."

Commit Snapshot

Saves staged changes permanently into local history with a message.

git log --oneline

Compact Log History

Shows commit history in clean single lines with hash IDs.

git checkout -b <name>

Create & Switch Branch

Creates a new isolated branch and switches your workspace to it immediately.

Module 04

Linking Local Git to GitHub.com

1. On GitHub.com Web UI

  1. Click the + icon in the top right header and select New repository.
  2. Provide a clear repo name (e.g., my-awesome-project).
  3. Important: Leave "Add a README file" unchecked if pushing an existing local project.
  4. Click Create repository and copy the HTTPS/SSH URL provided.

2. Terminal Link Commands

# 1. Add remote tracking URL
git remote add origin <REMOTE_URL>
# 2. Rename default branch to main
git branch -M main
# 3. Push and set upstream tracking
git push -u origin main
Module 05

The 5-Step Open Source Pipeline

1

Fork Repo

Click Fork on GitHub to copy the project under your own account.

2

Clone Local

Download your fork to your computer:

git clone <fork-url>
3

Branch Out

Never work on main! Create a branch:

git checkout -b feat/xyz
4

Push Feature

Push changes to your fork:

git push origin feat/xyz
5

Open PR

Go to original repo, click Compare & Pull Request. Write PR description!

Pro PR Tip: Linking GitHub Issues

When writing your Pull Request description on GitHub, include issue keywords like Fixes #42 or Closes #108. When maintainers merge your PR, GitHub will automatically close the referenced issue!

Module 06

Finding Issues & Community Etiquette

Beginner Issue Tags

Search GitHub Issues using these filters:

good first issue help wanted documentation

Read CONTRIBUTING.md

Every project has code guidelines, testing specs, and branch conventions in its CONTRIBUTING.md file. Always read it first!

Ask Before Working

Avoid duplicate work! Comment on an issue requesting assignment before coding:

"Hi maintainers! I'd like to work on this issue. Please assign it to me."
